# BakeCalc

Статические бесплатные инструменты для кондитеров. Серверная часть и сборка не нужны; страницы совместимы с GitHub Pages в подпапке `/baking_calc/`.

## Инструменты

- `index.html` — каталог.
- `bakecalc.html` — пересчёт рецепта под другую форму и себестоимость.
- `creamcalc.html` — крем для прослоек, верха и боков торта.
- `portioncalc.html` — рекомендуемый размер торта по количеству гостей и размеру порции.

В шапке и внизу каждого готового инструмента есть ссылка «На главную». Для новых страниц используйте `<a href="index.html" class="home-link">← На главную</a>`.

## PortionCalc

1. Укажите количество гостей и процент запаса.
2. Выберите размер порции: небольшая 4×8 см, стандартная 5×10 см, большая 6×10 см или задайте свой.
3. Выберите круглую или прямоугольную форму. Для прямоугольной формы можно задать желаемое соотношение длины к ширине.
4. Выберите шаг округления итогового размера и выполните расчёт.

Калькулятор работает по площади среза. Число порций с запасом округляется вверх до целого, затем определяется минимальная площадь торта. Для круга из площади вычисляется диаметр; для прямоугольника размеры подбираются по заданному соотношению сторон. Итоговые размеры округляются вверх выбранным шагом, чтобы после округления торт не оказался меньше расчётного.

Высота торта намеренно не участвует в модели: PortionCalc отвечает за площадь нарезки. Реальное число порций зависит от схемы нарезки и фактического размера кусков.

Параметры сохраняются отдельно под ключом `portioncalc_state_v1`. Старый результат скрывается после любого изменения параметров.

## CreamCalc

1. Укажите форму, размеры и высоту **собранного торта с прослойками, до внешнего покрытия**.
2. Укажите количество кремовых прослоек и их толщину. Для расчёта только покрытия задайте 0 прослоек.
3. Выберите покрытие верха и/или боков и задайте толщину.
4. Уточните плотность каждого крема и процент запаса. Нажмите «Рассчитать крем».

Размеры вводятся в сантиметрах, толщина — в миллиметрах, плотность — в г/мл. Поддерживаются точка и запятая. Плотность **1 г/мл — пример**, а не справочная характеристика любого крема. Чтобы определить свою, взвесьте 100 мл готового крема без ёмкости и разделите вес на 100.

Выводятся вес для каждой части, запас и общий вес. Количество для приготовления округляется вверх до 10 г. Модель предполагает ровные слои; дно, ягодная начинка, бордюры и крупный декор не учитываются.

Параметры сохраняются под отдельным ключом `creamcalc_state_v1`; рецепт BakeCalc (`bakecalc_state`) не затрагивается. После редактирования параметров старый результат скрывается до следующего расчёта. Если буфер обмена недоступен, предлагается текст для ручного копирования.

### Формулы CreamCalc

После перевода толщин в сантиметры: `A` — площадь торта, `H` — его высота, `s` — толщина боков, `t` — толщина верха.

- Круг: `A = πr²`; площадь оболочки `B = πs(2r + s)`.
- Прямоугольник: `A = L × W`; `B = 2s(L + W) + 4s²`.
- Прослойки: `V = A × толщина × количество`.
- Бока: `V = B × H`.
- Верх: `V = (A + B) × t`. При выключенных боках `B = 0`.
- Вес каждой части: `m = V × плотность`; общий запас: `сумма весов × процент / 100`.

Верх расположен над боковой оболочкой и включает её кромку; пересечение объёмов не считается дважды. Прямоугольное покрытие предполагает прямые углы.

## Разработка и проверка

Для локального запуска:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Для встроенных тестов нужен Node.js 18 или новее; установка npm-пакетов не требуется:

```sh
node --test tests/*.test.cjs
```

Чистая математика вынесена в `js/creamcalc-math.js`, `js/portioncalc-math.js` и `js/bakecalc-math.js`. Контроллеры страниц отвечают за DOM, сохранение состояния, ошибки и копирование. Tailwind, Inter и Lucide пока подключаются с CDN, поэтому для исходного оформления требуется сеть.

Разбор исходного репозитория и исторические проблемы: [docs/repository-review.md](docs/repository-review.md).
