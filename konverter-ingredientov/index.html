Масса, объём и плотность

Переводите граммы, килограммы, миллилитры и литры. Для перехода между массой и объёмом калькулятор попросит плотность ингредиента.

1

Что переводим

Введите количество и выберите исходную единицу.

2

Во что переводим

Выберите итоговую единицу. Единицы можно быстро поменять местами.

3

Плотность ингредиента

Нужна только для перевода между массой и объёмом.

1 г/мл подходит только для воды и близких по плотности жидкостей. Для других ингредиентов используйте их реальную плотность.

Как работает перевод?

Граммы и килограммы переводятся друг в друга напрямую. То же относится к миллилитрам и литрам.

Для массы → объём используется формула объём = масса / плотность. Для объёма → массу: масса = объём × плотность.

Плотность задаётся в г/мл. Универсального равенства «1 мл = 1 г» для всех ингредиентов не существует.
